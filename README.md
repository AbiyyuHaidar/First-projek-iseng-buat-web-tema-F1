# 🏎️ All About F1 IDN

Selamat datang di **All About F1 IDN** sebuah proyek web bertema Formula 1 yang dibuat untuk para penggemar F1 di Indonesia.  
Website ini menyajikan berbagai fitur seperti:
- 📅 Jadwal balapan terbaru  
- 🎥 Cuplikan video race terkini  
- 📰 Informasi dan statistik pembalap  
- 🏁 Form registrasi & login dengan tampilan modern
